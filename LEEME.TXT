

Versiones usadas:
PHP: 8.5.8
PostgreSQL:18.6

Requisitos:
PHP con las extensiones pdo_pgsql y pgsql habilitadas
PostgreSQL


Instalacion: 
1. Clonar el repositorio y abrir una terminal en la carpeta del proyecto.

2. Configurar la conexion a la base de datos:
   copiar php/config.example.php como php/config.php y editar host,
   puerto, usuario y contraseña de PostgreSQL.

3. Crear la base de datos ejecutando los siguienes comandos en la terminal:

En Windows (PowerShell), antes de usar psql, ejecutar:
        $env:PGCLIENTENCODING = "UTF8"

    (asegurarse que el puerto sea el correcto)
    psql -U postgres -p 5433 -c "CREATE DATABASE prueba_tecnica;"
    psql -U postgres -d prueba_tecnica -p 5433 -f sql/tablas.sql
    psql -U postgres -d prueba_tecnica -p 5433 -f sql/datos.sql
    psql -U postgres -d prueba_tecnica -p 5433 -f sql/funciones.sql

4. Iniciar el servidor de PHP desde la raiz del proyecto:
        php -S localhost:8000

5. Abrir en el navegador:
        http://localhost:8000/index.html
